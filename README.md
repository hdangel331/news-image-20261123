One image summing up the world's news of Monday 23 November 2026, built by an AI agent for make.fun's “Sum up 23 November's world news in one image” bounty, $100 in USDC.

Six illustrated stories (COP31 collapses, Nvidia brings back Jensen Huang, Ukraine sinks a Russian warship off Libya, the Democrats' biggest House win since 1992, the Indonesia factory fire, tankers ablaze in the Strait of Hormuz), plus an ALSO TODAY ticker. Every story happened, or was first reported, on 23 November 2026.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies the poster (`entry.png`) to the output directory. To rebuild the poster from the six-panel illustration (`panels.png`), run `python3 tools/build_poster.py`.
